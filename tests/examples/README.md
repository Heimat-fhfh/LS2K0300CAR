# PID库示例程序

这个目录包含了Control::PID库的使用示例程序。

## 文件结构

```
examples/
├── CMakeLists.txt      # CMake构建配置
├── pid_example.cpp     # 主示例程序
└── README.md           # 本文件
```

## 示例内容

示例程序包含了5个不同的PID使用场景：

1. **基础PID控制** - 展示基本的PID控制器使用
2. **带死区的PID控制** - 展示如何在误差小于死区时不进行控制
3. **带前馈的PID控制** - 展示如何结合前馈控制提高响应速度
4. **动态参数调整** - 展示如何在运行时调整PID参数
5. **重置和状态管理** - 展示如何重置控制器和管理状态

## 编译和运行

### 方法1：使用CMake（推荐）

```bash
# 创建构建目录
mkdir build
cd build

# 配置项目
cmake ..

# 编译
make

# 运行示例程序
./bin/pid_example
```

### 方法2：直接编译

```bash
# 直接使用g++编译
g++ -std=c++11 -I../include pid_example.cpp ../src/PID.cpp -o pid_example

# 运行
./pid_example
```

## 自定义示例

你可以修改`pid_example.cpp`文件来：

1. **调整PID参数**：修改`Kp`、`Ki`、`Kd`值
2. **更改控制周期**：调整`dt`值
3. **修改系统模型**：调整`SimulatedSystem`的时间常数
4. **添加新的控制场景**：参考现有示例添加新的测试

## 调试技巧

1. **观察误差变化**：关注误差如何随时间收敛
2. **调整限幅值**：如果系统振荡，尝试降低输出限幅
3. **启用/禁用抗积分饱和**：观察对系统稳定性的影响
4. **使用不同的死区大小**：观察对控制精度和执行器寿命的影响
