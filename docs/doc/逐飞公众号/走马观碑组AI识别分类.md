### 一、LS2K0300开源库更新
本次更新主要是移植了TFLite库的相关内容，这里为大家介绍一下TFLite库。TensorFlow Lite（简称TFLite）是谷歌推出的轻量化深度学习框架，核心目标是让TensorFlow训练的模型能在移动设备、嵌入式设备、物联网设备（如手机、平板、树莓派、智能手表、摄像头等）上高效运行，它不是一个训练框架，而是专注于模型部署和推理。其内部有成熟的API以及较为丰富的网络算子足以支持我们图像分类、目标检测、语言识别等模型的推理使用。

由于我们本次移植工作是直接进行的源码库的移植，所以这部分内容只需要大家更新一下开源库即可使用。

#### 2.1、Tensorflow环境搭建
主要过程为安装Python环境，搭建venv虚拟环境，通过pip指令下载安装模型训练所需要使用的tensorflow等环境依赖库。

1. 从“龙芯AI视觉相关文件.7z”中找到Python3.10.7版本的安装包，并解压安装。
2. 勾选“Add Python3.10 to Path”选项
3. 点击“Install Now”。
    - 此处需要记住Install Now下方的安装路径，后续需要使用。
4. 点击“Close”
5. 打开Vscode（若没有需要自行安装）
6. 打开vscode的拓展商店
7. 搜索python，找到Python拓展并点击安装
8. 随后，我们在桌面新建一个英文文件夹并使用vscode打开
9. 打开后，点击vscode右上角的切换面板键，打开控制台终端。
10. 在控制台终端输入`py -0`查看已安装python版本，这里我们看到有python-3.10-64版本即可。
11. 输入`py -3.10 -m venv venv` 创建虚拟环境
12. 我们在控制台继续输入`.\venv\Scripts\Activate.ps1`来激活我们的虚拟环境。激活成功后控制台命令前会出现`(venv)`的符号。
13. 接着复制粘贴输入下方四条指令，安装tensorflow的相关环境以及依赖。
    ```
    pip install tensorflow==2.10.0 -i https://mirrors.aliyun.com/pypi/simple/
    pip install numpy==1.23.4 -i https://mirrors.aliyun.com/pypi/simple/
    pip install pillow -i https://mirrors.aliyun.com/pypi/simple/
    pip install opencv-python==4.9.0.80 -i https://mirrors.aliyun.com/pypi/simple/
    ```
全部提示安装完成后，tensorflow相关环境的安装工作就结束了，可以开始训练模型了。
> 注：过程中没有反应可能是在解压缩安装包，需要耐心等待一会。

#### 2.2、模型训练
我们为了演示具体流程，为大家提供了一个较为简单的训练脚本。该脚本只保留了最基础的训练步骤。如果需要对模型进行优化，增加数据集增广处理，模型量化，模型二次训练等功能，需要同学们自行学习了解。

1. 在“龙芯AI视觉相关资料.7z”当中找到“模型训练资料”并将其内部的`datasets`文件夹以及`train.py`文件解压到我们当前的文件夹当中。
2. 向`datasets\image\train` 的各个类中添加数据集图片
    - 在从资料当中解压出来的train文件夹中已存入部分演示车模所使用的数据集图片用于展示如何训练。
3. 打开`train.py`修改训练参数
    - 注：训练参数中的设置的图像大小越大，每轮训练的时长越长。
4. 修改模型层级
    - 注：默认即可使用，后续使用可以自行优化。
5. 点击右上角启动`train.py`进行训练
6. 提示“成功生成TFLite文件!”并且文件夹中发现了`.tflite`文件。说明我们的训练成功了，并且生成了我们所需要的模型文件。

#### 2.3、部署模型文件
1. 将训练得到的`.tflite`文件放入开源库当中的`model`文件夹当中，并跳转到该文件夹路径下
2. 在控制台输入指令
    `xxd -i loong_cnn_model_simple.tflite loong_cnn_model_simple.h`
    将生成一个`loong_cnn_model_simple.h`文件。
3. 打开`loong_cnn_model_simple.h`文件，我们可以发现生成了一个二进制的数组以及一个变量。数组内存储的是模型的二进制信息，tflite库内部有相应的逻辑可以对其进行解析。变量则是保存的这个模型文件的大小。
4. 在这两个变量前添加`const`关键字，来防止头文件多次包含导致声明报错的问题。
5. 打开`zf_common_headfile.hpp` 将`loong_cnn_model_simple.h`的路径包含进去即可。

至此，我们的模型文件就已经准备就绪了。可以通过tflite库开始进行模型的推理了。

#### 2.4 、TFLite例程注意事项
这里在新的LS2K0300开源库当中提供了两个模型测试使用的例程。一个图片测试例程，一个摄像头测试例程。建议同学们前期先使用图片测试例程，了解熟悉分类模型的大致原理以及使用流程之后，再开始研究摄像头如何和模型推理部分进行结合使用。

1. 可以直接对`model`文件夹内的模型文件以及`.h`文件替换来测试自己训练的模型。
2. 我们打开例程的`main.c`文件。在上方可以看到我们模型推理的相关参数。若修改了训练脚本的相关参数，需自行对照修改为自己训练时所设置的模型参数。
3. 由于Opencv库当中的`imread`函数读到的图像信息以及摄像头读取到的图像信息默认均为BGR格式，而我们模型训练时一般使用RGB格式，模型参数量化默认为float类型，所以我们需要读取到的图像进行格式转换才可以使用。详细转换情况参考例程代码。 这里的转换过程是通过CV库的函数进行的。同学们了解过程后可以自行对其进行优化。
4. 在编译烧录后，需要添加测试的图片到龙芯核心板上，并将其改名为`test.jpg`。
    - 这里建议直接使用训练集内的图片，验证与训练效果是否一致。
5. 模型输出的原始信息实际为 0，1，2，而并非字符串，与训练例程当中log信息中显示出来的类一一对应。（类的顺序默认按首字母顺序排序）
    - 如下举例0对应`'materials'`，1对应`'traffic'`，2对应`'weapon'`。
6. 摄像头模型使用例程，主要为演示摄像头采集数据传入模型的过程以及体现模型推理速率，推理结果由于收到外界环境光的干扰，以及模型训练的拟合度，还有数据集是否完备等许多影响，无法保证。建议先使用图片测试模型，熟悉视觉流程之后再开始研究摄像头的使用。
