# 有源蜂鸣器库需求文档

## 1. 项目概述
为LS2K0300平台开发一个C++风格的有源蜂鸣器控制库，基于现有示例代码实现灵活的提示音控制功能。

## 2. 功能需求

### 2.1 基础功能
- 蜂鸣器的初始化与去初始化
- 蜂鸣器的开关控制（响/不响）
- 支持设置响铃时长和间隔时长

### 2.2 提示音模式
提供以下常用提示音模式：
- **单次短鸣**：响0.1秒
- **单次长鸣**：响0.5秒
- **双短鸣**：短响-间隔-短响
- **三短鸣**：短响-间隔-短响-间隔-短响
- **一长一短**：长响-间隔-短响
- **连续鸣叫**：持续响直到手动停止
- **自定义模式**：支持用户自定义响铃次数、时长和间隔

### 2.3 扩展性需求
- 采用面向接口设计，便于添加新的提示音模式
- 支持链式调用配置参数
- 可配置默认的短响、长响、间隔时间

## 3. 接口设计

### 3.1 蜂鸣器类（Buzzer）
```cpp
class Buzzer {
public:
    // 构造与析构
    explicit Buzzer(const char* device_path = "/dev/zf_driver_gpio_beep");
    ~Buzzer();
    
    // 基础控制
    void on();      // 打开蜂鸣器
    void off();     // 关闭蜂鸣器
    void beep(uint32_t duration_ms);  // 响指定时间后关闭
    
    // 提示音模式
    void shortBeep(uint32_t times = 1);           // 短鸣times次
    void longBeep(uint32_t times = 1);            // 长鸣times次  
    void patternDoubleShort();                     // 双短鸣
    void patternTripleShort();                      // 三短鸣
    void patternLongShort();                        // 一长一短
    void patternContinuous();                       // 连续鸣叫（需手动停止）
    void stop();                                    // 停止当前鸣叫
    
    // 自定义模式
    void customPattern(const std::vector<uint32_t>& on_times, 
                      const std::vector<uint32_t>& off_times,
                      uint32_t repeat_times = 1);
    
    // 配置设置（链式调用）
    Buzzer& setShortDuration(uint32_t ms);     // 设置短响时长
    Buzzer& setLongDuration(uint32_t ms);       // 设置长响时长
    Buzzer& setIntervalDuration(uint32_t ms);   // 设置间隔时长
    
    // 禁止拷贝
    Buzzer(const Buzzer&) = delete;
    Buzzer& operator=(const Buzzer&) = delete;
};
```

### 3.2 使用示例
```cpp
#include "buzzer.hpp"

int main() {
    Buzzer buzzer;  // 使用默认设备路径
    
    // 配置参数（链式调用）
    buzzer.setShortDuration(100)
          .setLongDuration(500)
          .setIntervalDuration(200);
    
    // 单次短鸣
    buzzer.shortBeep();
    
    // 三次短鸣
    buzzer.shortBeep(3);
    
    // 双短鸣模式
    buzzer.patternDoubleShort();
    
    // 自定义模式：响0.3秒停0.1秒，重复3次
    buzzer.customPattern({300}, {100}, 3);
    
    // 连续鸣叫5秒
    buzzer.patternContinuous();
    system_delay_ms(5000);
    buzzer.stop();
    
    return 0;
}
```

## 4. 实现要求

### 4.1 代码规范
- 使用C++11/14标准
- 遵循RAII原则，在析构函数中确保蜂鸣器关闭
- 使用constexpr定义默认参数
- 添加适当的异常处理
- 完善的注释（Doxygen风格）

### 4.2 性能要求
- 非阻塞模式，不占用CPU
- 支持异步操作（可选）

### 4.3 错误处理
- 设备文件打开失败时抛出异常
- GPIO操作失败时返回错误码或抛出异常
