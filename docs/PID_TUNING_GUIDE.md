# LS2K0300CAR 串级PID调参参考文档

---

## 一、系统架构概览

```
  视觉偏差 ──→ [归一化÷160] ──→ [LPF τ=0.02] ──→ ┌───────────────────────────┐
                                                  │  L1: 外环差速PD (Pure PD)  │
  IMU陀螺 ──→ [LPF τ=0.02] ────────────────────→ │  setpoint=0                │
                                                  │  反馈=归一化偏差 [-1,1]     │
  编码器 ──→ [LPF τ=0.02] ──────────────────┐    │  输出=期望差速(°/s)        │
                                            │    └───────────┬───────────────┘
                                            │                ▼
                                            │    ┌───────────────────────────┐
                                            │    │  L2: 内环角速度PI         │
                                            │    │  setpoint=期望差速        │
                                            └───→│  反馈=陀螺角速度 Z (°/s)  │
                                                  │  输出=最终差速量 [-0.7,0.7]│
                                                  └───────────┬───────────────┘
                                                              │ diffOutput
  ┌────────────────────────────────────────────────────────┐  │
  │  L3: 速度环增量式PID                                    │  │
  │  setpoint=期望线速度 (m/s)  反馈=左右编码器均值          │←─┘
  │  输出=speedOutput [-0.7, 0.7]                         │
  └───────────────────────┬────────────────────────────────┘
                          │
          ┌───────────────┴───────────────┐
          ▼                               ▼
   leftCmd = speedOutput - diffOutput    rightCmd = speedOutput + diffOutput
          │                               │
          ▼                               ▼
   Motor PWM [死区,最大占空比50%]        Motor PWM
```

- **控制频率**：100Hz（dt = 10ms）
- **差速混合式**：左=速度-差速，右=速度+差速（差速项控制转向，速度项控制前进）
- **UDP遥测**：10 维 float 数组发往上位机，可实时监控各层输出

## 二、L1 外环差速PD

```
功能：将视觉偏差（归一化像素误差）转换为期望角速度差

算法：u = clamp( Kp*e + Kd*de/dt, ±limitOutput )
      - P项限幅 ±limitP
      - D项限幅 ±limitD
      - Ki 硬编码为 0（纯PD，无积分）
```

### 当前参数

| 参数 | 低速 | 中速 | 高速 | 说明 |
|------|:----:|:----:|:----:|------|
| `DIFF_OUTER_PD_KP` | 8.0 | 10.0 | 12.0 | 比例增益 |
| `DIFF_OUTER_PD_KD` | 1.5 | 2.0 | 2.5 | 微分增益 |
| `DIFF_OUTER_PD_LIMIT_P` | 30.0 | 40.0 | 50.0 | P项输出限幅 |
| `DIFF_OUTER_PD_LIMIT_D` | 15.0 | 20.0 | 25.0 | D项输出限幅 |
| `DIFF_OUTER_PD_LIMIT_OUTPUT` | 150.0 | 200.0 | 250.0 | 总输出限幅(°/s) |

### 调参步骤

| 步骤 | 操作 | 判据 |
|------|------|------|
| 1 | 先设 Kd=0，增大 Kp | 直到车开始小幅振荡 |
| 2 | Kp 回退 20-30% | 稳定基准 |
| 3 | 逐步增大 Kd | 抑制振荡，提高响应速度 |
| 4 | 设置 limitP / limitD | P项限制幅度，D项防过激 |
| 5 | 调整 limitOutput | 限制最大期望差速 |

### 调整依据

| 现象 | 可能原因 | 对策 |
|------|---------|------|
| 直线蛇形振荡 (0.5-2Hz) | Kp 过大 | 降低 Kp 或增大 Kd |
| 入弯响应慢 | Kp 不足 | 增大 Kp |
| 弯内持续偏移（稳态偏差） | 纯PD无积分，固有残差，由内环PI补偿 | 无需调整此处 |
| D项引入高频抖动 | Kd 过大 或 limitD 不够 | 降低 Kd 或收紧 limitD |

### 注意事项

- **归一化除数160**（`main.cpp` 中 `SteerErrorPx / 160.0`）是隐藏的Kp缩放因子。图像分辨率或视场角改变时，此值需同步修改。
- limitOutput=150~250 的实际单位是 °/s（期望角速度），180°/s 约等于 0.5 秒旋转一圈。
- 外环输出无积分意味着**直线也可能有微小稳态横向偏差**，但在差速+陀螺闭环下通常可忽略。

## 三、L2 内环角速度PI

```
功能：用IMU陀螺仪跟踪外环给出的期望角速度差，提供角速度闭环

算法：位置式 PID（Kd=0，实际为PI）
      - 抗积分饱和：当输出饱和且误差方向与积分同向时，反转积分
      - I项下限 limitIMin 用于非对称抗饱和
```

### 当前参数

| 参数 | 低速 | 中速 | 高速 | 说明 |
|------|:----:|:----:|:----:|------|
| `DIFF_INNER_PI_KP` | 15.0 | 12.0 | 15.0 | 比例增益 |
| `DIFF_INNER_PI_KI` | 0.8 | 0.6 | 0.8 | 积分增益 |
| `DIFF_INNER_PI_KD` | 0.0 | 0.0 | 0.0 | 微分（保持为0） |
| `DIFF_INNER_PI_LIMIT_P` | 60.0 | 60.0 | 60.0 | P项限幅 |
| `DIFF_INNER_PI_LIMIT_I` | 30.0 | 30.0 | 30.0 | I项限幅 |
| `DIFF_INNER_PI_LIMIT_D` | 0.0 | 0.0 | 0.0 | D项限幅（未使用） |
| `DIFF_INNER_PI_LIMIT_OUTPUT` | 0.7 | 0.7 | 0.7 | **总输出限幅(PWM占空比)** |
| `DIFF_INNER_PI_LIMIT_I_MIN` | -0.7 | -0.7 | -0.7 | 积分下限 |
| `DIFF_INNER_PI_ANTI_WINDUP` | true | true | true | 抗积分饱和 |

### 调参步骤

| 步骤 | 操作 | 判据 |
|------|------|------|
| 1 | 先设 Ki=0，增大 Kp | 直到角速度跟踪出现振荡 |
| 2 | Kp 回退 20% | 建立P基准 |
| 3 | 逐步增大 Ki | 消除角速度稳态误差 |
| 4 | 设置 limitI | 限制积分累积量 |
| 5 | **limitOutput=0.7 是关键瓶颈** | 决定最大差速占空比 |

### 调整依据

| 现象 | 可能原因 | 对策 |
|------|---------|------|
| 弯道内侧轮停转 | diffOutput饱和于0.7，speedOutput被挤占 | 增大limitOutput（上限1.0）或降低速度 |
| 出弯后持续晃动 | Ki 过大 | 降低 Ki 或减小 limitI |
| 曲线跟踪滞后明显 | Ki 太小，角速度有稳态偏差 | 增大 Ki |
| IMU漂移导致直线偏移 | 积分累积了偏置 | 减小 limitI / 增大 limitIMin 绝对值 |

### 注意事项

- **limitOutput=0.7 是最紧瓶颈**：0.7 意味着差速输出最多占 PWM 的 70%。当 speedOutput=0.5 时，diffOutput 达到 0.7 就会让一侧电机停转（0.5-0.7=-0.2 → clamp 到 0）。
- IMU 信号经过 LPF（Tau=0.02, alpha=0.333），已滤除高频噪声，故 Kd 保持为 0 是合理的。
- 如果 IMU 失效，diffOutput 会直接透传外环输出值（开环控制）。

## 四、L3 速度环增量式PID

```
功能：跟踪期望线速度（视觉决策输出），提供速度闭环

算法：增量式PID
      Δu = Kp*(e_k - e_{k-1}) + Ki*e_k*dt + Kd*(e_k - 2e_{k-1} + e_{k-2})/dt
      u_k = clamp(u_{k-1} + Δu, ±limitOutput)

优点：积分分离自然、参数切换平滑、无稳态积分饱和
```

### 当前参数

| 参数 | 低速 | 中速 | 高速 | 说明 |
|------|:----:|:----:|:----:|------|
| `SPEED_INCR_PI_KP` | 0.4 | 0.5 | 0.5 | 比例增益 |
| `SPEED_INCR_PI_KI` | 0.4 | 0.5 | 0.5 | 积分增益 |
| `SPEED_INCR_PI_KD` | 0.0 | 0.0 | 0.0 | 微分增益（按需启用） |
| `SPEED_INCR_PI_LIMIT_OUTPUT` | 0.7 | 0.7 | 0.7 | 总输出限幅(PWM占空比) |

### 调参步骤

| 步骤 | 操作 | 判据 |
|------|------|------|
| 1 | 先设 Ki=0，Kd=0，增大 Kp | 直到速度响应出现超调 |
| 2 | Kp 回退 ~30%，加入 Ki | 消除稳态速度误差 |
| 3 | 如需要更平滑响应，加 Kd | 抑制速度过冲 |
| 4 | 调整 limitOutput | 限制最大PWM占空比 |

### 调整依据

| 现象 | 可能原因 | 对策 |
|------|---------|------|
| 速度响应慢 | Kp 太小 | 增大 Kp |
| 稳态速度偏差明显 | Ki 太小 | 增大 Ki |
| 速度超调大 | Kp / Ki 过大 | 降低或启用 Kd |
| 启动后速度缓慢爬升 | Kp+Ki 联合增益不足 | 按比例同增 Kp 和 Ki |
| 下坡时速度增大 | 制动能力受限（只能降PWM，无法主动制动） | 注意 Kp 和 Ki 只影响减速幅度 |

### 注意事项

- **limitOutput=0.7** 限制了平稳行驶时电机最大占空比约为 0.7×50% = 35%。
- 速度环和差速环共享 limitOutput=0.7，两者叠加后左/右电机的总命令会被更大的差速输出挤占。
- **Kd 默认 0.0**：编码器低通滤波（tau=0.02, alpha=0.333）已提供平滑效果，Kd一般不需要。若启用 Kd，编码器量化噪声可能被放大（除以 10ms 的 dt 相当于放大 100 倍）。

## 五、硬件标定参数

### 电机/编码器参数

| 参数 | 值 | 备注 |
|------|-----|------|
| 编码器齿数 | 30 | |
| 电机齿数 | 68 | |
| 减速比 | 30/68 ≈ 0.441 | |
| 轮径 | 6.5 cm | |
| 轮周长 | π×0.065 ≈ 20.42 cm | |
| 轮距 | ≈15.8 cm | |
| 编码器转换系数 | 0.00901 m/s per RPS | `0.1 × wheel_rps × circumference` |
| PWM最大值 | 10000 (占空比级数) | |
| PWM死区 | 0.01 (1%) | 1%以下占空比电机不转动 |
| 死区补偿 | `(speed-deadZone)/(1-deadZone)` | 将 [0.01, 1] 映射到 [0, 1] |
| 最大占空比 | 50% (JSON可配) | 对应 dutyValue = 5000 |
| 反向 | 不支持 (负值 clamp 到 0) | |

### 低通滤波器

| 滤波器 | Tau | dt | Alpha (α) | 公式 |
|--------|:---:|:--:|:---------:|------|
| 左轮速度 | 0.02 | 0.01 | 0.333 | `filtered = α·raw + (1-α)·last` |
| 右轮速度 | 0.02 | 0.01 | 0.333 | 同上 |
| 角速度 | 0.02 | 0.01 | 0.333 | 同上 |
| 归一化偏差 | 0.02 | 0.01 | 0.333 | 同上 |

- α=0.333 表示新数据仅贡献 33%，旧数据保留 67%。会引入约 3-5 个采样周期（30-50ms）的相位延迟。
- **响应慢 → 降低 Tau**（如 Tau=0.005 → α=0.667）
- **信号抖 → 增大 Tau**（如 Tau=0.05 → α=0.167）

| 对比项 | config_0 (低速) | config_1 (中速) | config_2 (高速) |
|--------|:--------------:|:--------------:|:--------------:|
| 直道速度 | 60 | 75 | 90 |
| 外环 KP / KD | 8.0 / 1.5 | 10.0 / 2.0 | 12.0 / 2.5 |
| 内环 KP / KI | 15.0 / 0.8 | 12.0 / 0.6 | 15.0 / 0.8 |
| 速度环 KP / KI | 0.4 / 0.4 | 0.5 / 0.5 | 0.5 / 0.5 |
| 适用场景 | 基础调试，稳定优先 | 日常比赛，平衡响应 | 高速赛道，直道多 |

### 跨速调参规律

| 规律 | 原因 |
|------|------|
| 随速度↑，外环 Kp/Kd 需↑ | 高速时相同偏差需要更大力矩纠正 |
| 内环 Kp 保持较高 | 角速度跟踪带宽不能降低 |
| 内环 Ki 在高速下需↑ | 高速转弯角速度跟随需求大，积分需更快 |
| 速度环增益随速度↑ | 高速时需更大 PWM 输出来维持线速度 |

## 七、调参方法（推荐流程）

### 阶段一：离线标定
1. **PWM死区标定**：执行 `./program MotorDead`，自动检测电机最小启转占空比
2. **编码器标定**：推车对比编码器读数与实际距离，确认转换系数
3. **IMU零偏标定**：静止时读取 gyroZ，确保零偏 < 0.5°/s

### 阶段二：内环优先调参
1. **速度环调参**：固定车在直线上，设置恒定速度 setpoint，调 Kp/Ki 使速度跟踪平滑
2. **差速内环调参**：固定车在原地，施加阶跃 gyro setpoint（如 50°/s），调 Kp/Ki 使角速度跟踪快且无振荡

### 阶段三：外环联调
1. 内环/速度环保持不动
2. **外环 Kp**：从 1.0 开始，每次 +1.0，直到入弯响应足够快
3. **外环 Kd**：从 0.5 开始，每次 +0.5，直到直线稳定无蛇形
4. **limitOutput 微调**：确保内外环总输出不超过电机最大占空比

### 阶段四：高低速适配
1. 先在低速 config 上调到最优
2. 提高速度到中速，按比例同增外环增益
3. 提高速度到高速，检查差速饱和度

## 九、常见问题排查

| 症状 | 可能原因 | 检查方向 |
|------|---------|---------|
| 直线剧烈蛇形 | 外环 KP 过大 或 KD 过小 | 降低 KP 或 增大 KD |
| 直线缓慢摇摆 | 外环 KD 过大 或 LPF 太重 | 降低 KD 或 降低 LPF Tau |
| 入弯过冲 | 外环 D 不够 或 limitOutput 太小 | 增大 KD 或 放宽 limitOutput |
| 弯道内侧轮停止 | 差速饱和 (diffOutput=0.7) | 降低速度 或 放宽内环 limitOutput |
| 出弯加速冲出路 | 速度环 Ki 过大，出弯时差速回0慢 | 降低 Ki 或 检查外环 D 的恢复 |
| 直道加速/减速后持续抖动 | 速度环增量累积过大 | 检查速度环 Kp/Ki 乘积 |
| 碰障碍后行为异常 | 碰撞保护触发 | 按 KEY0 复位（如已配置） |
| 越跑越偏 | IMU 积分漂移 | 检查 IMU 零偏 和 内环 KI 大小 |
| 车轮空转不减速 | 编码器读取异常 | 检查编码器连接和读取函数 |

## 十、UDP遥测数据格式（调试参考）

```cpp
std::array<float, 10> data = {
    [0] desiredSpeed,       // 期望速度 (m/s)
    [1] avgSpeed,           // 平均速度 (m/s)
    [2] currentError,       // 归一化偏差 [-1,1]
    [3] desiredDiffSpeed,   // 外环PD输出(期望差速 °/s)
    [4] gyroZ,              // 陀螺仪角速度 (°/s)
    [5] diffOutput,         // 内环PI输出(最终差速 PWM 占空比)
    [6] speedOutput,        // 速度环输出 (PWM 占空比)
    [7] leftCmd,            // 左电机命令
    [8] rightCmd,           // 右电机命令
    [9] diffInnerIntegral   // 内环积分累积值
};
```

调整时重点关注：**data[2]（偏差）→ data[3]（外环响应）→ data[5]（内环响应）→ data[6]（速度响应）**，检查各环节是否有饱和或振荡。
